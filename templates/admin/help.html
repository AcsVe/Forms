1. Create a form

New form → a blank form, a template, or Paste text or script (a question list, JSON, or a Google Apps Script) with a live preview. Every change in the designer is saved automatically.

2. Questions

28 types: short answer, paragraph, email, phone, link, number, multiple choice, checkboxes, dropdown, yes/no, image choice, linear scale, rating, NPS, slider, Likert, grids, ranking, constant sum, date, time, date and time, file upload, signature, hidden field, sections (pages) and text/image/video blocks.

Display rules: open a question → "Show this question only if…". Branching: next to each option of a one-choice question choose the section to go to, or "submit the form". A section can also have "After this section go to".

3. Look

Colour, font, header image, background image, looping muted video and background music (the respondent starts it with a button). Two languages: turn on "Two languages" and fill the English fields; respondents get a language switch.

4. Access

By default anyone with the link can answer, and the server records device, browser, system, IP, screen and time zone. Optional: email sign-in with a six-digit code (needs mail set up), allowed domains, one response per email or per device, and a "respondent details" step (name, phone, grade…).

5. Quiz

Quiz tab → turn on. Each question gets points and a correct answer; paragraphs are marked by hand on the response page. Choose whether to show the score and the right answers after submitting, and a pass mark.

6. Share

Set the status to Open, then Share: link, QR code (SVG for printing), WhatsApp, email and embed code. A link with preset hidden fields records where a response came from.

7. Sub-forms

A sub-form is linked to a parent form; its links appear on the parent's thank-you page and its response is linked to the parent response.

8. Analysis

Each form: charts for every question, averages, NPS, satisfaction, grids, word frequency, quiz results, segment filters, a cross-tab of any two questions with a chi-square test, Excel/CSV/JSON export. Compare forms: indicators, monthly responses, devices, grouping by category, owner, month, device or browser, and shared questions side by side.

١. إنشاء نموذج

«نموذج جديد» ← نموذج فارغ، أو قالب، أو «لصق نص أو سكربت» (قائمة أسئلة، أو JSON، أو سكربت Google Apps Script) مع معاينة فورية قبل الإنشاء. كل تعديل في صفحة التصميم يُحفظ تلقائياً.

٢. الأسئلة

ثمانية وعشرون نوعاً: نص قصير، فقرة، بريد، هاتف، رابط، رقم، اختيار من متعدد، مربعات اختيار، قائمة منسدلة، نعم/لا، اختيار بالصور، مقياس خطي، تقييم، مؤشر صافي الترويج NPS، شريط تمرير، مقياس ليكرت، شبكات، ترتيب، توزيع النقاط، تاريخ، وقت، تاريخ ووقت، رفع ملف، توقيع، حقل مخفي، أقسام (صفحات)، ونص أو صورة أو فيديو.

شرط الإظهار: افتح السؤال ← «شرط إظهار السؤال». التفرّع: بجانب كل خيار في سؤال الاختيار الواحد اختر القسم الذي ينتقل إليه المستجيب أو «إرسال النموذج»، وللقسم أيضاً «بعد هذا القسم انتقل إلى».

٣. المظهر

اللون، والخط، وصورة الترويسة، وصورة الخلفية، وفيديو الخلفية (صامت ومتكرر)، وموسيقى الخلفية (يشغّلها المستجيب بزر). نموذج بلغتين: فعّل «نموذج بلغتين» واكتب حقول الإنجليزية، فيظهر للمستجيب زر تبديل اللغة.

٤. الدخول

افتراضياً يجيب أي شخص معه الرابط، ويسجّل الخادم الجهاز والمتصفح والنظام وعنوان IP والشاشة والمنطقة الزمنية. ويمكن طلب الدخول بالبريد برمز من ستة أرقام (يحتاج إعداد البريد)، وتحديد نطاقات البريد، وإجابة واحدة لكل بريد أو جهاز، وخطوة «بيانات المستجيب» (الاسم، الهاتف، الصف…).

٥. الاختبار

تبويب «الاختبار» ← تفعيل. لكل سؤال درجة وإجابة صحيحة، والفقرات تُصحَّح يدوياً من صفحة الإجابة. اختر إظهار الدرجة والإجابات الصحيحة بعد الإرسال، ودرجة النجاح.

٦. المشاركة

غيّر الحالة إلى «مفتوح» ثم «مشاركة»: الرابط، ورمز QR (SVG للطباعة)، وواتساب، والبريد، وكود التضمين. والرابط بقيم مسبقة للحقول المخفية يسجّل مصدر الإجابة.

٧. النماذج الفرعية

النموذج الفرعي مرتبط بنموذج أم؛ تظهر روابطه في صفحة الشكر للنموذج الأم، وتُربط إجابته بإجابة النموذج الأم.

٨. التحليل

لكل نموذج: رسوم لكل سؤال، والمتوسطات، وNPS، ونسبة الرضا، والشبكات، والكلمات الأكثر تكراراً، ونتائج الاختبار، والتصفية بالشريحة، وجدول متقاطع لأي سؤالين مع اختبار كاي تربيع، والتصدير إلى Excel وCSV وJSON. و«المقارنة بين النماذج»: المؤشرات، والإجابات شهرياً، والأجهزة، والتجميع حسب التصنيف أو صاحب النموذج أو الشهر أو الجهاز أو المتصفح، والأسئلة المشتركة جنباً إلى جنب.
