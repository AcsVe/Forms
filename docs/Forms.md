# دليل نظام النماذج والاستبيانات (FORMS)

> العنوان: `https://9.iajaward.org` · المنفذ `8009` · المجلد `C:\Forms` · القاعدة `data\forms.db`
> **آخر تحديث: 2026-11-04 (بتوقيت عمّان).**

## 1) ما الذي يقدّمه النظام

نظام لإنشاء النماذج والاستبيانات والاختبارات (على نمط Google Forms وMicrosoft Forms وSurveyMonkey وIpsos) وجمع الإجابات وتحليلها.

| المجال | ما يقدّمه |
|---|---|
| أنواع الأسئلة (28) | نص قصير، فقرة، بريد، هاتف، رابط، رقم، اختيار من متعدد (مع «أخرى»)، مربعات اختيار (حد أدنى وأعلى)، قائمة منسدلة، نعم/لا، اختيار بالصور، مقياس خطي، تقييم (نجوم/قلوب/وجوه/إبهام)، NPS، شريط تمرير، ليكرت، شبكة اختيار واحد، شبكة مربعات، ترتيب، توزيع النقاط، تاريخ، وقت، تاريخ ووقت، رفع ملفات، توقيع، حقل مخفي من الرابط، قسم (صفحة)، نص أو صورة أو فيديو |
| المنطق | شروط إظهار لكل سؤال أو قسم (كل الشروط / أي شرط؛ يساوي، يحتوي، أكبر من…)، وتفرّع: كل خيار ينقل إلى قسم أو إلى الإرسال، ولكل قسم «بعده انتقل إلى». الخادم يعيد حساب المنطق ولا يحفظ إجابات الأسئلة المخفية |
| الاختبار | درجة لكل سؤال، إجابات صحيحة (ونصوص مقبولة وسماحية للأرقام ودرجة جزئية)، تصحيح يدوي للفقرات، درجة النجاح، إظهار الدرجة والإجابات الصحيحة بعد الإرسال، ملاحظات للإجابة الصحيحة والخاطئة |
| المظهر | لون رئيسي، خط، بطاقات بيضاء أو زجاجية، صورة ترويسة، **صورة خلفية، فيديو خلفية، موسيقى خلفية** (بزر يشغّله المستجيب)، تعتيم الخلفية |
| اللغة | الواجهة عربية وإنجليزية مع مبدّل؛ النموذج عربي (RTL) أو إنجليزي (LTR)، أو **بلغتين** مع زر تبديل للمستجيب |
| الإنشاء | فارغ، أو من قالب، أو **لصق نص أو JSON أو سكربت Google Apps Script** مع معاينة قبل الإنشاء، أو استيراد ملف بنية مُصدَّر |
| الوصول | بلا دخول (يُسجَّل على الخادم: الجهاز، المتصفح وإصداره، النظام، IP، الشاشة، النافذة، المنطقة الزمنية، لغة المتصفح، المصدر، المدة)، أو **بالدخول بحساب Microsoft للمدرسة** (Microsoft Graph، التسجيل نفسه الذي تستخدمه الأنظمة الأخرى) أو **برمز من ستة أرقام يصل إلى البريد** أو بالطريقتين، مع حصر النطاقات، و**خطوة بيانات المستجيب** (الاسم، الهاتف، الصف… بحقول تختارها) |
| الحدود | فتح وإغلاق بموعد (توقيت عمّان)، حد أعلى للإجابات، إجابة واحدة لكل بريد أو جهاز، مهلة بالدقائق مع عدّاد وإرسال تلقائي، حقل مصيدة للبرامج الآلية، حد للسرعة، تعليم «تكرار محتمل» |
| المشاركة | رابط، **رمز QR لكل نموذج** بشعار الجهة واسمها وعنوان النموذج، يُنشأ في النظام نفسه دون خدمة خارجية، ويُحمَّل PNG أو SVG ويُطبع من صفحة خاصة، ولكل نسخة رمزها؛ واتساب، بريد، كود تضمين، رابط بقيم مسبقة للحقول المخفية |
| النماذج الفرعية | نموذج مرتبط بنموذج أم؛ روابطه في صفحة الشكر، وإجابته مربوطة بإجابة الأم وتظهران معاً |
| النسخ والقوالب | نسخ نموذج (يحتفظ بمعرّفات الأسئلة فتسهل المقارنة)، حفظه قالباً، خمسة قوالب جاهزة |
| اللوحة الرئيسية | كل رقم قابل للضغط ويفتح القائمة المُصفّاة؛ الإجابات خلال 30 يوماً، الأجهزة، المتصفحات، ساعات الإجابة، التصنيفات، أصحاب النماذج |
| التحليل | لكل سؤال: رسم وجدول، المتوسط والوسيط والانحراف، NPS، نسبة الرضا، الشبكات، الترتيب، الكلمات الأكثر تكراراً، نسبة الإجابات الصحيحة؛ التصفية بالتاريخ والجهاز والشريحة؛ **جدول متقاطع** لأي سؤالين مع اختبار كاي تربيع؛ نسبة الإكمال (فتح ← بدء ← إرسال) |
| المقارنة | بين نماذج مختارة أو تصنيف كامل: المؤشرات، الإجابات شهرياً، الأجهزة، التجميع حسب النموذج أو التصنيف أو صاحب النموذج أو الحالة أو الشهر أو الجهاز أو المتصفح أو النظام، والأسئلة المشتركة جنباً إلى جنب |
| التصدير | Excel (ورقة الإجابات وورقة التحليل)، CSV بالعربية السليمة، JSON، وبنية النموذج |
| للمستجيب | حفظ المسودة في جهازه، شريط تقدّم، رقم الصفحة، صفحة شكر مع إجاباته وطباعتها PDF، نسخة بالبريد |

### إضافات لا تتوفر مجتمعةً في تلك المنتجات
خلفية فيديو وموسيقى، لصق سكربت Google Apps Script، النماذج الفرعية المربوطة بإجابات الأم، اختبار كاي تربيع في الجدول المتقاطع، المقارنة بين نماذج بمعايير متعددة والأسئلة المشتركة، تعليم التكرار من الجهاز نفسه، مهلة الإجابة مع الإرسال التلقائي، كل شيء على خادم المدرسة دون اشتراك.

### الجداول والقوائم
كل جدول: رؤوس ثابتة، وبحث عام فوقه، وتصفية تحت كل عمود، وترتيب بالضغط على العنوان، وتحديد متعدد مع إجراءات جماعية (فتح، إغلاق، نسخ، أرشفة، حذف محمي…)، وتصدير الصفوف الظاهرة إلى ملف يفتحه Excel.

## 2) المستخدمون والصلاحيات
- **مسؤول**: يرى كل النماذج، ويدير المستخدمين والإعدادات.
- **محرّر**: يرى نماذجه فقط، ويستخدم كل القوالب.
- الحذف المحمي: لا يُحذف نموذج له إجابات أو نماذج فرعية (يُؤرشف بدلاً من ذلك)، ولا مستخدم له نماذج (يُعطّل)، ولا آخر مسؤول، ولا الحساب الحالي.
- **الدخول (بنمط القاعات):** اسم المستخدم أو البريد، وإظهار كلمة المرور، و«تذكرني على هذا الجهاز»، و«نسيت كلمة المرور؟» (رابط بالبريد عبر Microsoft Graph صالح ساعة ولمرة واحدة). تغيير كلمة المرور يُخرج الجلسات القديمة، وعشر محاولات خاطئة من الجهاز نفسه توقف الدخول خمس عشرة دقيقة.
- أول مسؤول يُنشأ من `ADMIN_USER` و`ADMIN_PASS` في `.env` عند أول تشغيل (يضعهما `1_setup.bat`)، ويمكن تغيير كلمة المرور من «حسابي».

## 3) التثبيت على كمبيوتر المدرسة (القالب المشترك)
1. انسخ المستودع إلى `C:\Forms`.
2. `1_setup.bat`: البيئة والمكتبات وملف `.env` (يأخذ مجلد Drive ورمز Cloudflare وإعدادات البريد من نظام آخر على الجهاز إن وُجد) والقاعدة وربط `9.iajaward.org`.
3. `3_autostart.bat` **كمسؤول**: البدء مع ويندوز + نسخة كل ساعة + المراقب كل 5 دقائق.
4. التحديث بعد ذلك: `update.bat` فقط.

| الملف | العمل |
|---|---|
| `2_start.bat` | تشغيل يدوي للتجربة |
| `forms_on.bat` / `forms_off.bat` | تشغيل/إيقاف هذا النظام فقط |
| `forms_check.bat` | فحص الموقع والعنوان العام وآخر نسخة، وتشغيله إن كان متوقفاً |
| `backup_now.bat` / `restore_backup.bat` | نسخة الآن / استرجاع (يحفظ نسخة أمان أولاً) |
| `site_where.bat` / `switch_to_server.bat` / `back_to_server.bat` | أين يشير العنوان / إعادته للكمبيوتر / أخذ بيانات الهاتف بعد الطوارئ |
| `stop_autostart.bat` | إلغاء المهام |

- النسخ الاحتياطية في `IAJ-backups/forms` على Google Drive (القاعدة تشمل الملفات المرفوعة: الخلفيات والموسيقى والفيديو ومرفقات المستجيبين).
- الهاتف الاحتياطي: `standby/phone.sh` (المجلد `~/forms`، النفق `forms-standby`).
- الدخول الآمن يعمل عبر https فقط (`SECURE_COOKIES=1`).

### الدخول بحساب Microsoft للمدرسة
يستخدم قيم `MS_TENANT_ID` و`MS_CLIENT_ID` و`MS_CLIENT_SECRET` في `.env` (التسجيل نفسه للبريد في الأنظمة الأخرى). مرة واحدة في بوابة Azure ← تسجيل التطبيق:
1. Authentication ← Web ← Redirect URI: `https://9.iajaward.org/auth/ms/callback` (يظهر جاهزاً للنسخ في «الإعدادات»).
2. API permissions ← Microsoft Graph ← Delegated: `openid` و`profile` و`email` و`User.Read`، ثم «Grant admin consent».

في النموذج: «الدخول والمستجيب» ← «يتطلب الدخول» ← طريقة الدخول (حساب Microsoft أو رمز البريد أو كلاهما). اسم صاحب الحساب يملأ حقل «الاسم» في خطوة بيانات المستجيب.

## 4) صيغة لصق الأسئلة
```
# عنوان النموذج
> وصف النموذج
1. سؤال مطلوب *
2. سؤال اختيار [قائمة]
- خيار
- خيار صحيح ✓
## قسم جديد
3. قيّم [شبكة]
| ممتاز | جيد | ضعيف |
- عبارة أولى
4. ملاحظاتك [فقرة] [2 درجات]
```
الأنواع بين القوسين: `[فقرة] [تاريخ] [وقت] [رقم] [بريد] [هاتف] [قائمة] [متعدد] [نعم لا] [تقييم] [1-10] [NPS] [شريط] [ليكرت] [شبكة] [ترتيب] [توزيع] [ملف] [توقيع]` (وتُقبل الأسماء الإنجليزية). `[ ]` قبل الخيار = مربعات اختيار.

## 5) للمطوّر
| الملف | المحتوى |
|---|---|
| `app.py` | التطبيق، اللغة، الهوية، عرض الملفات |
| `models.py` | الجداول والترحيل الآلي (`MIGRATIONS`) |
| `schema.py` | أنواع الأسئلة، التنظيف، الصفحات، المنطق، التحقق، التصحيح |

| `analytics.py` / `exporter.py` | الإحصاءات والجداول المتقاطعة والمقارنة / Excel وCSV |
| `blueprints/admin.py` / `blueprints/public.py` | لوحة الإدارة / صفحات المستجيبين |
| `static/js/builder.js` / `fill.js` / `charts.js` | المحرّر / التعبئة (نسخة المنطق في المتصفح) / الرسوم |
| `tests/` | `pytest` للمسارات الرئيسية، و`e2e_browser.py` للفحص في Chrome (سطح المكتب والهاتف) |
